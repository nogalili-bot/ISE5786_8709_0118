# 1. הדמיית עומק שדה (Depth of Field)
   הבעיה:
   במנועי רינדור בסיסיים, כל האובייקטים בסצנה מופיעים בחדות מושלמת ללא קשר למרחקם מהמצלמה. התוצאה היא מראה "ממוחשב" וחסר עומק, שאינו מדמה את המציאות שבה עדשות מצלמה יוצרות טשטוש (Blur) על עצמים המרוחקים ממישור המוקד.

הפתרון:
מימשנו הדמיית עומק שדה פיזיקלית באמצעות דגימה על גבי שטח העדשה (Aperture). במקום להטיל קרן אחת ממרכז המצלמה, אנו מפיקים אלומת קרניים (Ray Beam) מנקודות שונות על העדשה, המכוונות כולן לנקודת המוקד. השתמשנו בשקלול אדפטיבי כדי להתאים את עוצמת הטשטוש לפי המרחק ממישור המוקד, מה שמעניק לתמונות מראה קולנועי וריאליסטי.

# 2. האצת ביצועים גיאומטרית: מבנה נתונים BVH
   הבעיה:
כאשר הסצנה כוללת אלפי פרימיטיבים, בדיקת חיתוך של כל קרן מול כל גוף היא פעולה יקרה מאוד חישובית (O(n)), שיוצרת צוואר בקבוק משמעותי בזמן הרינדור.

הפתרון:
הטמענו מבנה נתונים מסוג BVH (Bounding Volume Hierarchy). המערכת בונה היררכיית תיבות תוחמות (Bounding Boxes) המקיפות את האובייקטים. בתהליך הרינדור, הקרן בודקת חיתוך מול התיבה; אם אין חיתוך, מתבצע Early Cutoff (חסימה מוקדמת) המדלג על כל תת-הסצנה שבתוך התיבה. שיפור זה מאפשר רינדור מהיר בסדרי גודל עבור סצנות מורכבות.
